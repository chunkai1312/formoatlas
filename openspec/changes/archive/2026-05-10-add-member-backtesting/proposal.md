## 背景與動機

FormoAtlas 已有會員登入、自選股、個股頁與 5 年 OHLC 資料，但使用者目前只能閱讀盤後脈絡，無法驗證「某個交易規則在歷史上是否接近自己的報酬目標」。會員限定回測可以把既有資料轉成可操作的研究工具，先從單股均線策略開始，後續延伸到自選股批次回測與目標報酬導向的選股 / 資產配置模擬。

## 變更內容

- 新增會員限定的單股回測 API，未登入使用者不得執行回測。
- 使用 `node-backtesting` 作為回測引擎，先支援買進持有與 SMA 均線交叉策略。
- 將既有 ticker OHLC 資料轉換成 `node-backtesting` historical data；第一版以「股」為交易單位，不限制整張。
- 回測結果不儲存，只回傳當次績效摘要、權益曲線、回撤序列、交易明細與策略參數。
- 個股頁新增回測區塊；未登入時顯示登入提示，登入後可設定策略參數並執行。
- 規劃目標報酬導向策略模擬 capability，作為後續從「目標金額 / 年化報酬 / 期限 / 風險限制」反推候選選股或資產配置策略的基礎。

## 能力範圍

### 新增能力

- `member-backtesting`：會員限定單股策略回測。
- `goal-based-strategy-simulation`：目標報酬導向的候選策略與資產配置模擬規格。本次僅定義需求與資料形狀，不列入第一階段實作。

### 修改能力

- `stock-detail-page`：個股頁新增回測入口與登入 gate。

## 影響範圍

- **後端**：新增 `BacktestingModule`、受 JWT guard 保護的回測 controller、回測 service、策略 adapter 與 DTO。
- **前端**：個股頁新增回測面板與圖表呈現；新增 backtesting service/model。
- **依賴**：新增 `node-backtesting`，可能搭配 `technicalindicators` 使用 SMA。
- **資料庫**：第一階段不新增 collection、不保存回測結果。
- **風險揭露**：UI 與 API response 需標示回測為歷史模擬，不構成投資建議，不保證未來績效。

## 非目標

- 第一階段不允許使用者提交自訂 JavaScript 策略。
- 第一階段不儲存回測紀錄。
- 第一階段不做付費會員分級，只要求已註冊 / 已登入會員。
- 第一階段不做自選股批次回測、全市場掃描或最佳化 heatmap。
- 第一階段不直接產生買賣建議或保證達標結論。
